# Contributing to OpenClaw CRM Skill

Thanks for your interest in contributing! Here's how to get started.

## How to Contribute

1. Fork the repo
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Write/update tests
5. Submit a PR with a clear description

## Areas We Need Help

- **CRM Adapters**: Salesforce, Pipedrive, Monday.com, Freshsales
- **Lead Scoring**: ML-based scoring models, custom scoring criteria
- **Testing**: Unit tests, integration tests with CRM APIs
- **Documentation**: Usage examples, video walkthroughs

## Code Style

- Python: Follow PEP 8
- TypeScript: Follow the existing project conventions
- Keep functions small and well-documented
